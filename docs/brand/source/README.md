# UnitWave Studio — App Brand Assets

This set is designed for the actual application rather than as a generic logo sheet.

- `unitwave-app-icon.svg`: detailed dark app icon with glow
- `unitwave-app-icon-flat.svg`: same vector geometry without glow
- `unitwave-splash-dark.svg`: dark startup / About screen
- `unitwave-splash-light.svg`: light startup / About screen
- `unitwave-navbar-dark.svg`: compact in-app header lockup
- `unitwave-navbar-light.svg`: compact light-theme header lockup
- `unitwave-mark-detailed.svg`: detailed ribbon mark only

The mark uses closed Bézier ribbon surfaces, layered gradients, highlights, underside shading,
tapered ends and controlled overlap—not simple stroked wave lines.

For application deployment, keep SVG as the source of truth and export platform-specific PNG/ICO/ICNS
assets from the app-icon master during the build/release process.
