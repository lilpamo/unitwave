Other ways in

Open a Phy folder

The events file is read with this task's column names, events and conditions. A file without the columns it needs is refused, naming them.

Events on another clock? Add sync pulses

The same sync pulses recorded on each clock, under the folder root: CatGT edge files (one time per line) or IBL's _spikeglx_sync.times files. The events are moved onto the probe's clock along a line (offset plus drift).

From histology alignment: the IBL alignment GUI's channel_locations.json, or a CSV of channel, ccf_ap_um, ccf_dv_um, ccf_ml_um and acronym. Each unit takes its peak channel's region and position, so the region tree and the brain view work.

Open an NWB file

The layout declares what the dataset's files hold (quality column, regions, behaviour); without one, the file is read generically. Anything the file holds outside what Studio reads is listed on the session page, with the reason.
